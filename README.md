Proyecto académico de bases de datos orientado a la gestión deportiva. El material del proyecto incluye la administración de atletas, entrenadores, grupos, sesiones de entrenamiento, asistencia y pagos.

### Alcance del proyecto

- Modelos conceptual, lógico y físico de la base de datos.
- Scripts de implementación para Microsoft SQL Server.
- Restricciones para mantener la integridad y las relaciones entre los datos.
- Vistas para consultar información del sistema e índices para apoyar las consultas.
- Funciones, procedimientos almacenados y disparadores para implementar reglas de negocio.
- Datos de prueba, scripts de validación y documentación del diseño.
